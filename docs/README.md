# MineIntent 文档

`docs/` 只维护少量不会与代码竞争“当前事实”的项目级活文档：

- [产品宪法草案](../PRODUCT_CONSTITUTION.md)：产品根本原则、决定权边界、效力与修订规则。
- [运行世界参与原型](./guides/companion-prototype.md)：安装、配置、启动和故障排查。
- [Paper 集成测试](./guides/paper-integration.md)：隔离世界中的 Backend/Paper 验证范围。
- [来源索引](./source-index.md)：初始目标、关键 PR/Issue、后续纠正和当前维护者澄清之间的关系。

## 真相边界

- “产品为什么存在”以依确认程序生效后的产品宪法为准。
- “程序现在做什么”以目标提交的代码、类型、测试和真实运行证据为准。
- “以前为什么这样做”查来源索引、Git、Issue 和 PR；历史材料不因更早或已合并自动成为现行决定。
- 未决工作保留在 GitHub Issue，不复制成仓库内长期提案。
