## 中间层落地前的底层缺口清单

下列项目是从上述逐项对照直接归并出的“当前没有足够底层事实，不能仅靠类型改名可靠补齐”的缺口；是否由 backend-rs、适配层或协议新版本承担，留给接缝设计裁定（`任务书.md:23`、`任务书.md:31`）。

1. **观测事件生产缺口**：实体六类增量事件完全没有生产者；方块只有 chunk loaded，没有 block updated/chunk unloaded；声音只有 kind 占位，没有 heard payload；由后端生产还是 adapter 差分待 SEAM-13（`materials/mineintent-main/src/minecraft/contracts.ts:153-191`；`materials/backend-rs/src/runtime.rs:274-305`、`materials/backend-rs/src/runtime.rs:993-1184`）。
2. **结构化生命周期事实缺口**：断开只保存 reason，连接失败只保存调试字符串；缺 close/failure DTO 所需的 code、retryable、deliberate、kick/error 细节，也缺 faulted/stopped/respawn transition 的契约事件（`materials/mineintent-main/src/minecraft/contracts.ts:38-62`、`materials/mineintent-main/src/minecraft/contracts.ts:200-212`；`materials/backend-rs/src/runtime.rs:236-247`、`materials/backend-rs/src/runtime.rs:1096-1139`、`materials/backend-rs/src/runtime.rs:335-350`）。
3. **配置执行能力缺口**：Microsoft 登录/profile 目录、connect/login/spawn/stop 分阶段 timeout、可禁用及带 multiplier/max/jitter/stable reset 的重连策略均未进入 `RunConfig` 或执行路径（`materials/mineintent-main/src/minecraft/contracts.ts:11-24`；`materials/backend-rs/src/runtime.rs:45-73`、`materials/backend-rs/src/runtime.rs:1188-1228`、`materials/backend-rs/src/runtime.rs:1246-1255`）。
4. **快照细节、字段与 revision 语义缺口**：世界天气/时间/难度/视距，自身氧气/effects，物品 metadata/durability，玩家手持物，以及实体 name/head yaw/手持物/装备没有完整输出；self/entity key、alive/valid、块 properties/transparentHint 与两类 revision 的来源/推进规则也不同，规范化待 SEAM-13（`materials/mineintent-main/src/minecraft/snapshot.ts:37-114`、`materials/mineintent-main/src/minecraft/dto.ts:29-74`、`materials/mineintent-main/src/minecraft/minecraft-backend.ts:625-632`；`materials/backend-rs/src/snapshot.rs:39-169`、`materials/backend-rs/src/snapshot.rs:214-264`、`materials/backend-rs/src/snapshot.rs:329-375`、`materials/backend-rs/src/snapshot.rs:450-519`、`materials/backend-rs/src/runtime.rs:199-203`）。
5. **聊天 wire/可信度元数据缺口**：接收事件没有 position/verified，现有 rawText/receivedAt 不能替代；无 sender 时 Rust 又写 JSON null，而 TS 可选 string 是缺席或字符串，需在冻结 wire/adapter 中规范化（`materials/mineintent-main/src/minecraft/contracts.ts:193-198`；`materials/backend-rs/src/runtime.rs:1086-1095`）。
6. **可取消命令与完成边界缺口**：start/look/move 没有逐调用取消信号，stop 没有可等待的完成边界或最终 stopped 事件（`materials/mineintent-main/src/minecraft/contracts.ts:265-285`；`materials/backend-rs/src/runtime.rs:417-456`、`materials/backend-rs/src/runtime.rs:833-945`、`materials/backend-rs/src/runtime.rs:1232-1288`）。
7. **epoch 隔离与 observation 订阅缺口**：TS 观察句柄固定创建时 epoch，旧句柄拒绝读取且订阅只交付同 epoch 的 observation 事件；Rust 句柄直接跟随共享当前 epoch，订阅又收到全部 backend kinds（`materials/mineintent-main/src/minecraft/minecraft-backend.ts:209-241`；`materials/backend-rs/src/runtime.rs:501-587`）。
8. **命令可用期与同步释放缺口**：TS 在非 ready 时拒绝 sendChat/motor，并让 releaseAll 在返回前清 controls；Rust 对外方法只入队，未 ready 的非 respawn 命令随后继续保留，因而 stale command 的归属和 release 完成时点尚未对齐（`materials/mineintent-main/src/minecraft/minecraft-backend.ts:196-207`、`materials/mineintent-main/src/minecraft/motor-driver.ts:65`；`materials/backend-rs/src/runtime.rs:411-445`、`materials/backend-rs/src/runtime.rs:977-990`）。
9. **事件 dimension 事实缺口**：TS 在事件发生时从 active bot 盖上 dimension；Rust 信封构造器总写 `None` 且 runtime 不覆盖，适配层无法仅凭迟到事件恢复“发生时所在维度”（`materials/mineintent-main/src/minecraft/minecraft-backend.ts:647-660`；`materials/backend-rs/src/protocol.rs:62-85`、`materials/backend-rs/src/runtime.rs:112-135`）。
10. **复合移动键语义缺口**：TS 对所有 1–4 个不重复方向逐键按下；Rust 接受同一 input shape，却只映射无相反键的单键/双键。四种三键组合在 TS 会保留未抵消轴、Rust 则映射 `None`；相反二键/四键虽净位移同为零，按键状态仍不同。抵消/拒绝策略待 SEAM-14（`materials/mineintent-main/src/minecraft/motor-driver.ts:33-63`；`materials/backend-rs/src/runtime.rs:795-810`）。
11. **首次 attempt 信封归属缺口**：TS 在 `connection_requested` 前建立 epoch/attemptId；Rust 先用默认 epoch 0/`attempt-0` 发该事件，直到客户端 `Init` 才 `new_attempt()`，使同一次连接的生命周期信封横跨两个身份；归属模型待 SEAM-15 裁定（`materials/mineintent-main/src/minecraft/minecraft-backend.ts:244-280`；`materials/backend-rs/src/runtime.rs:88-107`、`materials/backend-rs/src/runtime.rs:999-1005`、`materials/backend-rs/src/runtime.rs:1246-1250`）。

下列是“底层事实大体存在，但当前公开边界不兼容”的接缝项：公开 `BackendState/state()`、原子 `BackendReady` 返回、`self`/`self_state` 与生命周期 discriminator/字段对齐、显式 unsubscribe、独立 motor accessor，以及 TS `1.21.1` 字面量与 Rust `26.1.2`/775 的协议版本表达（`materials/mineintent-main/src/minecraft/contracts.ts:13`、`materials/mineintent-main/src/minecraft/contracts.ts:26-36`、`materials/mineintent-main/src/minecraft/contracts.ts:200-285`；`materials/backend-rs/src/protocol.rs:27-60`、`materials/backend-rs/src/runtime.rs:354-587`、`materials/backend-rs/src/runtime.rs:993-1288`）。本表只登记差异，不选择兼容方案。
