# TS → Rust 模块清单

## 0. 基线、范围与口径

- 本清单只做移植规划；TypeScript 行为基线是 `materials/mineintent-main` commit `6fb3ed0c007601b4e1eb1cb0a9d10525ac2a2467`，Rust 后端基线是 `materials/backend-rs` commit `5868c7e32ca3aa8bd9beda9355b898c19690d014`（`任务书.md:5-7`、`任务书.md:13-18`）。
- `src/` 在该 TS commit 下共有 105 个 `.ts` 文件、11,574 个物理行：其中 **78 个非 `*.test.ts` 文件共 7,699 行**，细分为 75 个非 `information/testing/` 主体/入口文件共 7,580 行，以及 3 个非测试的 testing helper 共 119 行；另有 27 个 `*.test.ts` 共 3,875 行（TS commit `6fb3ed0`；各非测试文件的首尾行见下表）。`src/test.ts` 虽是测试入口，仍计入前述 75 个主体/入口文件（`materials/mineintent-main/src/test.ts:1-9`）。
- “规模”统一指含空行与注释的物理行数，不是复杂度或移植工时；聚合数字绑定上述 TS commit，文件级数字同时给出 `文件:首行-末行`。
- “Rust 重叠”分三种：**已有**表示 Rust 已有同层行为或 wire shape；**底层已供给**表示 Rust 只提供 provider/中间层所需原始事实，TS 的策略仍须迁；**无**表示在 Rust 生产源码中没有对应中间层实现。Rust crate 当前只公开 `protocol/runtime/snapshot/viewport` 四个模块（`materials/backend-rs/src/lib.rs:1-6`），所以不能把“底层已供给”误写成“中间层已完成”。
- Rust 后端固定 Paper 26.1.2 / 协议 775，使用 `azalea 0.16.0`；TS Minecraft 后端固定 1.21.1 / Mineflayer（`materials/backend-rs/README.md:1-3`、`materials/backend-rs/Cargo.toml:1-15`、`materials/mineintent-main/src/minecraft/config.ts:4-15`）。因此，下文的“重叠”是职责/行为重叠，不等于 DTO 已逐字段兼容。
- 视口的实现所有权仍不在本文裁定：TS 算法位于 `information/source-ports/perception.ts`，provider 位于 `information/providers/viewport-provider.ts`；Rust 已有独立 `viewport.rs`，并声明参数与主仓库算法对齐（`materials/mineintent-main/src/information/source-ports/perception.ts:91-176`、`materials/mineintent-main/src/information/providers/viewport-provider.ts:87-150`、`materials/backend-rs/src/viewport.rs:1-5`、`materials/backend-rs/src/viewport.rs:40-68`）。
